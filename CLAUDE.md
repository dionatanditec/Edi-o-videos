# CLAUDE.md

Repositório de edição de vídeos com o Claude Code: cortar, juntar, legendar,
formato vertical 9:16 e tratamento de áudio, usando ferramentas gratuitas.

## Antes de qualquer tarefa

1. Ler o `INDEX.md`.
2. Ler todos os arquivos da pasta `memoria/`:
   - `memoria/sobre-mim.md` — quem é o Dionatan e a Ditec Instalação
   - `memoria/estilo-de-edicao.md` — como os vídeos devem ficar
   - `memoria/ambiente.md` — ferramentas e sites disponíveis neste ambiente
   - `memoria/decisoes.md` — decisões já tomadas (não refazer o que já foi decidido)

## Regras

- **Nunca instalar skill, agente ou plugin de terceiros sem aprovação do Dionatan.**
  Pedir aprovação explicitamente antes, explicando o que é e de onde vem.
- **Ler o código antes de instalar** qualquer coisa de terceiros (scripts,
  pacotes, skills, plugins) e resumir para o Dionatan o que ele faz.
- **Nunca colocar senhas, tokens ou chaves de API nos arquivos** do repositório.
- Registrar em `memoria/decisoes.md` toda decisão relevante (ferramenta escolhida,
  padrão de edição, mudança de regra), com data.
- Atualizar `memoria/ambiente.md` quando o ambiente mudar (nova ferramenta, novo acesso).
- **Vídeos e áudios não vão para o GitHub** (pesam demais). Ficam só no computador do Dionatan.
  O repositório guarda apenas instruções, memória e scripts. O `.gitignore` já bloqueia esses arquivos.
